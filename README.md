# PSU Smart Schedule — Web Demo

เว็บต้นแบบแบบ static สำหรับสาธิตแนวคิด PSU Smart Schedule

- เปิดหน้า `index.html` เพื่อเริ่มที่หน้าเข้าสู่ระบบตัวอย่าง
- กด **ทดลองด้วยบัญชีตัวอย่าง** เพื่อเข้าโหมดสาธิต
- ข้อมูลรายวิชา ตารางเรียน และการแจ้งเตือนเป็นข้อมูลสมมติ
- ไม่มีการเชื่อมต่อ PSU Passport หรือ SIS จริง และไม่ควรกรอกรหัสผ่านจริง

## เผยแพร่ด้วย GitHub Pages

1. สร้าง repository ชื่อ `psu-smart-schedule` แล้วอัปโหลดไฟล์ชุดนี้ไปที่ branch `main`
2. เปิด **Settings → Pages**
3. ที่ **Build and deployment** เลือก **Deploy from a branch**
4. เลือก branch `main` และโฟลเดอร์ `/(root)` แล้วกด **Save**
5. รอ GitHub สร้างเว็บไซต์ แล้วเปิด URL ที่แสดงในหน้า Pages (โดยทั่วไปคือ `https://<username>.github.io/psu-smart-schedule/`)

> GitHub Pages เป็นเว็บไซต์สาธารณะ แม้ repository จะเป็น private เมื่อแผนบัญชีรองรับ โปรดตรวจเนื้อหาและข้อมูลก่อนเผยแพร่
